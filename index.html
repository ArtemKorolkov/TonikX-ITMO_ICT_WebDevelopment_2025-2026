Отчеты по лабораторным работам по дисциплине «Web-программирование»¶

Автор: Корольков Артем
Группа: К3340

Введение¶

Данный отчет содержит результаты выполнения лабораторных и практических работ по дисциплине «Web-программирование». Цель курса — освоить принципы разработки клиент-серверных приложений на Python, включая работу с сетевыми протоколами, веб-серверами и современными веб-фреймворками.

В отчёт включены материалы следующих лабораторных работ:

Лабораторная работа №1 — Клиент-серверные приложения на Python¶

Цель:¶

Освоить основы сетевого программирования с использованием библиотеки socket и реализовать простые сетевые приложения.

Основные задания:¶

  1. UDP-клиент и сервер.
  2. TCP-клиент и сервер для вычисления площади параллелограмма.
  3. HTTP-сервер, возвращающий HTML-страницу.
  4. Многопользовательский чат (TCP).
  5. Мини-веб-сервер с обработкой GET и POST запросов.

Результат:¶

Разработаны и протестированы клиент-серверные приложения для различных протоколов, отработаны навыки работы с потоками и базовыми HTTP-заголовками.

Лабораторная работа №2 — Django Web Framework¶

Цель:¶

Изучить принципы построения веб-приложений с использованием Django-фреймворка.

Состав работы:¶

  1. Практическая работа №1 — установка Django, создание проекта и моделей, настройка маршрутов и админ-панели.
  2. Практическая работа №2 — реализация CRUD-операций (создание, чтение, редактирование, удаление) с применением FBV и CBV.
  3. Практическая работа №3 — расширение пользовательской модели (AbstractUser), добавление полей и создание интерфейса регистрации пользователя.
  4. Лабораторная работа — список отелей.

Результат:¶

Создано полноценное Django-приложение с административной панелью, шаблонами и формами; реализованы CRUD-операции и кастомная модель пользователя.

Лабораторная работа 3. Реализация серверной части на django rest. Документирование API.¶

Цель:¶

Овладеть практическими навыками реализации серверной части (backend) приложений средствами Django REST framework.

Состав работы:¶

  1. Практическая работа №1 — работа с запросами в Django ORM.
  2. Практическая работа №2 — использование возможностей работы контроллеров и серриализаторов в Django Rest Framework.
  3. Практическая работа №3 — написание документации к API.
  4. Лабораторная работа — реализация серверной части приложения средствами django и djangorestframework.

Результат:¶

Реализован сайт, используя фреймворк Django 3, Django REST Framework, Djoser и СУБД PostgreSQL *, в соответствии с вариантом задания лабораторной работы.

Лабораторная работа 4. Реализация клиентской части средствами Vue.js.¶

Цель:¶

Ознакомится с базовыми конструкциями JavaScript. Получить представление о работе Vue.js. Получить практические навыки настройки CORS (Cross-origin resource sharing).

Состав работы:¶

  1. Практическая работа №1 — ликбез JS.
  2. Практическая работа №2 — введение в Vue.js.
  3. Практическая работа №3 — настройка CORS (Cross-origin resource sharing).
  4. Лабораторная работа — реализация клиентской части приложения средствами vue.js.

Результат:¶

Реализованы интерфейсы авторизации, регистрации и изменения учётных данных и настроено взаимодействие с серверной частью.
