Цель работы¶

Овладеть практическими навыками и получить представление о работе Vue.js.

Исходное задание¶

  • Реализовать интерфейсы авторизации, регистрации и изменения учётных данных и настроить взаимодействие с серверной частью.
  • Реализовать клиентские интерфейсы и настроить взаимодействие с серверной частью.
  • Подключить vuetify или аналогичную библиотеку.

Вариант задания: Система управления гостиницей¶

Создать программную систему, предназначенную для администратора гостиницы. Система должна обеспечивать хранение сведений об имеющихся в гостинице номерах, о проживающих в гостинице клиентах и о служащих, убирающихся в номерах.

Требования к данным¶

Номера:

  • Количество номеров известно
  • Три типа: одноместный, двухместный, трехместный
  • Отличаются стоимостью проживания в сутки
  • В каждом номере есть телефон

Клиенты:

  • Номер паспорта, ФИО, город, дата поселения, выделенный номер

Служащие:

  • ФИО, этаж, день недели уборки
  • Служащий убирает все номера на одном этаже в определенные дни недели

Функциональные требования¶

Информационные запросы:

  • О клиентах, проживавших в заданном номере в заданный период
  • О количестве клиентов, прибывших из заданного города
  • О том, кто из служащих убирал номер указанного клиента в заданный день недели
  • Сколько в гостинице свободных номеров
  • Список клиентов с указанием места жительства, которые проживали в те же дни, что и заданный клиент

Операции администратора:

  • Принять на работу или уволить служащего
  • Изменить расписание работы служащего
  • Поселить или выселить клиента

Отчетность:

  • Автоматическая выдача отчета о работе гостиницы за указанный квартал
  • Число клиентов за период в каждом номере
  • Количество номеров на каждом этаже
  • Общая сумма дохода за каждый номер
  • Суммарный доход по всей гостинице

2. Описание основных интерфейсов¶

2.1 Панель управления¶

Назначение: Отображение общей информации о состоянии гостиницы.

Функциональность:

  • отображение количества номеров;
  • отображение количества свободных номеров;
  • быстрый доступ к основным разделам системы.

2.2 Управление номерами¶

Назначение: Просмотр и управление номерным фондом.

Возможности:

  • просмотр списка всех номеров;
  • отображение этажа, типа номера, наличия телефона;
  • определение статуса номера (свободен / занят).

2.3 Клиенты¶

Назначение: Работа с информацией о клиентах гостиницы.

Возможности:

  • просмотр списка клиентов;
  • использование данных в аналитических запросах;
  • выбор клиента для определения уборщика номера.

2.4 Сотрудники¶

Назначение: Управление персоналом гостиницы.

Функциональность:

  • отображение списка сотрудников;
  • использование данных сотрудников в расписании уборки.

2.5 Услуги гостиницы¶

Назначение: Отображение перечня услуг, предоставляемых гостиницей.

Функциональность:

  • таблица услуг;
  • отображение названия и описания услуги;
  • данные загружаются с backend (/api/hotel-services/).

Примеры услуг:

  • Обслуживание номеров
  • Ресепшен
  • Обслуживание мероприятий

2.6 Аналитика¶

Назначение: Получение статистических данных для принятия управленческих решений.

Реализованные аналитические запросы:

  • количество клиентов по выбранному городу;
  • поиск уборщика, обслуживавшего номер клиента в заданный день недели.

Заключение¶

Реализация клиентской части (дополнительно)¶

  • Разработан полноценный SPA-интерфейс на Vue.js + Vuetify
  • Реализованы интерфейсы авторизации и регистрации
  • Созданы CRUD интерфейсы для всех сущностей системы
  • Реализована панель управления с аналитикой
  • Настроено взаимодействие с серверной частью через Axios
