Цель работы¶

Овладеть практическими навыками и умениями реализации web-сервисов средствами Django.

Исходное задание¶

Реализовать сайт, используя фреймворк Django 3, Django REST Framework, Djoser и СУБД PostgreSQL *, в соответствии с вариантом задания лабораторной работы.

Вариант задания: Система управления гостиницей¶

Создать программную систему, предназначенную для администратора гостиницы. Система должна обеспечивать хранение сведений об имеющихся в гостинице номерах, о проживающих в гостинице клиентах и о служащих, убирающихся в номерах.

Требования к данным¶

Номера: - Количество номеров известно - Три типа: одноместный, двухместный, трехместный - Отличаются стоимостью проживания в сутки - В каждом номере есть телефон

Клиенты: - Номер паспорта, ФИО, город, дата поселения, выделенный номер

Служащие: - ФИО, этаж, день недели уборки - Служащий убирает все номера на одном этаже в определенные дни недели

Функциональные требования¶

Информационные запросы: - О клиентах, проживавших в заданном номере в заданный период - О количестве клиентов, прибывших из заданного города - О том, кто из служащих убирал номер указанного клиента в заданный день недели - Сколько в гостинице свободных номеров - Список клиентов с указанием места жительства, которые проживали в те же дни, что и заданный клиент

Операции администратора: - Принять на работу или уволить служащего - Изменить расписание работы служащего - Поселить или выселить клиента

Отчетность: - Автоматическая выдача отчета о работе гостиницы за указанный квартал - Число клиентов за период в каждом номере - Количество номеров на каждом этаже - Общая сумма дохода за каждый номер - Суммарный доход по всей гостинице

1. Модель базы данных средствами DjangoORM¶

Основные модели¶
# hotel_app/models.py
class CustomUser(AbstractUser):
    email = models.EmailField(unique=True)
    is_hotel_staff = models.BooleanField(default=False)
    is_admin = models.BooleanField(default=False)

class RoomType(models.Model):
    name = models.CharField(max_length=50, verbose_name="Тип номера")
    capacity = models.PositiveIntegerField(verbose_name="Вместимость")
    price_per_night = models.DecimalField(max_digits=10, decimal_places=2)

class Room(models.Model):
    room_number = models.CharField(max_length=10, unique=True)
    floor = models.PositiveIntegerField(verbose_name="Этаж")
    room_type = models.ForeignKey(RoomType, on_delete=models.PROTECT)
    has_phone = models.BooleanField(default=True)
    is_available = models.BooleanField(default=True)

class Client(models.Model):
    passport_number = models.CharField(max_length=20, unique=True)
    last_name = models.CharField(max_length=50)
    first_name = models.CharField(max_length=50)
    middle_name = models.CharField(max_length=50, blank=True)
    city = models.CharField(max_length=100)
    check_in_date = models.DateTimeField(auto_now_add=True)

class Staff(models.Model):
    user = models.OneToOneField(CustomUser, on_delete=models.CASCADE)
    last_name = models.CharField(max_length=50)
    first_name = models.CharField(max_length=50)
    middle_name = models.CharField(max_length=50, blank=True)
    is_active = models.BooleanField(default=True)

class CleaningSchedule(models.Model):
    staff = models.ForeignKey(Staff, on_delete=models.CASCADE)
    floor = models.PositiveIntegerField(verbose_name="Этаж")
    day_of_week = models.CharField(max_length=3, choices=DAYS_OF_WEEK)

class Stay(models.Model):
    client = models.ForeignKey(Client, on_delete=models.CASCADE)
    room = models.ForeignKey(Room, on_delete=models.CASCADE)
    check_in_date = models.DateField(verbose_name="Дата заселения")
    check_out_date = models.DateField(null=True, blank=True)
    total_cost = models.DecimalField(max_digits=12, decimal_places=2, default=0)

ViewSets с аналитическими методами¶

# hotel_app/views.py
class RoomViewSet(viewsets.ModelViewSet):
    queryset = Room.objects.all()
    serializer_class = RoomSerializer

    @action(detail=False, methods=['get'])
    def available_rooms(self, request):
        """Количество свободных номеров в гостинице"""
        available_count = Room.objects.filter(is_available=True).count()
        return Response({'available_rooms': available_count})

class ClientViewSet(viewsets.ModelViewSet):
    queryset = Client.objects.all()
    serializer_class = ClientSerializer

    @action(detail=False, methods=['get'])
    def from_city(self, request):
        """Количество клиентов из заданного города"""
        city = request.query_params.get('city', '')
        if city:
            count = Client.objects.filter(city__iexact=city).count()
            return Response({'city': city, 'count': count})
        return Response({'error': 'Не указан город'}, status=400)
