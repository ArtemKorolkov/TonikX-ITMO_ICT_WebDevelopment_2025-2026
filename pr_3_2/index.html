Отчет по практической работе №3.2¶

Django REST Framework¶

Цель: Освоить принципы RESTful API и научиться создавать API endpoints с использованием Django REST Framework, включая работу с сериализаторами и Generic-классами.

Теоретическая основа¶

  • REST (Representational State Transfer) - архитектурный стиль для создания веб-сервисов
  • Сериализация - процесс преобразования объектов в формат для передачи (JSON)
  • Generic-классы - готовые представления для стандартных операций CRUD

Задание 1: Эндпоинты для навыков¶

Постановка задачи¶

Реализовать эндпоинты для добавления и просмотра навыков (Skills) используя APIView.

Реализация¶

  • Модель Skill
# warriors_app/models.py
class Skill(models.Model):
    title = models.CharField(max_length=120, verbose_name='Наименование')

    def __str__(self):
        return self.title
  • Сериализатор SkillSerializer
# warriors_app/serializers.py
from rest_framework import serializers
from .models import Skill

class SkillSerializer(serializers.ModelSerializer):
    class Meta:
        model = Skill
        fields = "__all__"
  • Представление SkillAPIView
# warriors_app/views.py
from rest_framework.views import APIView
from rest_framework.response import Response
from rest_framework import status
from .models import Skill
from .serializers import SkillSerializer

class SkillAPIView(APIView):
    def get(self, request):
        skills = Skill.objects.all()
        serializer = SkillSerializer(skills, many=True)
        return Response({"Skills": serializer.data})

    def post(self, request):
        skill_data = request.data
        serializer = SkillSerializer(data=skill_data)

        if serializer.is_valid(raise_exception=True):
            skill_saved = serializer.save()
            return Response(
                {"Success": "Skill '{}' created successfully.".format(skill_saved.title)},
                status=status.HTTP_201_CREATED
            )
  • Маршрутизация
# warriors_app/urls.py
from django.urls import path
from .views import SkillAPIView

urlpatterns = [
    path('skills/', SkillAPIView.as_view(), name='skills'),
]

Задание 2: Расширенные эндпоинты для воинов¶

Постановка задачи¶

Реализовать эндпоинты для работы с воинами, включая вывод связанных данных и операции CRUD.

Реализация¶

  • Расширенные сериализаторы
# warriors_app/serializers.py
class ProfessionSerializer(serializers.ModelSerializer):
    class Meta:
        model = Profession
        fields = ["title", "description"]

class SkillSerializer(serializers.ModelSerializer):
    class Meta:
        model = Skill
        fields = ["title"]

class WarriorProfessionSerializer(serializers.ModelSerializer):
    profession = ProfessionSerializer()
    race = serializers.CharField(source="get_race_display", read_only=True)

    class Meta:
        model = Warrior
        fields = ["id", "name", "race", "level", "profession"]

class WarriorSkillSerializer(serializers.ModelSerializer):
    skill = SkillSerializer(many=True)
    race = serializers.CharField(source="get_race_display", read_only=True)

    class Meta:
        model = Warrior
        fields = ["id", "name", "race", "level", "skill"]

class WarriorFullSerializer(serializers.ModelSerializer):
    profession = ProfessionSerializer()
    skill = SkillSerializer(many=True)
    race = serializers.CharField(source="get_race_display", read_only=True)

    class Meta:
        model = Warrior
        fields = "__all__"
  • Generic-представления
# warriors_app/views.py
from rest_framework import generics
from .models import Warrior
from .serializers import WarriorProfessionSerializer, WarriorSkillSerializer, WarriorFullSerializer

class WarriorProfessionListAPIView(generics.ListAPIView):
    serializer_class = WarriorProfessionSerializer
    queryset = Warrior.objects.all()

class WarriorSkillListAPIView(generics.ListAPIView):
    serializer_class = WarriorSkillSerializer
    queryset = Warrior.objects.all()

class WarriorRetrieveAPIView(generics.RetrieveAPIView):
    serializer_class = WarriorFullSerializer
    queryset = Warrior.objects.all()

class WarriorDestroyAPIView(generics.DestroyAPIView):
    queryset = Warrior.objects.all()

class WarriorUpdateAPIView(generics.UpdateAPIView):
    serializer_class = WarriorFullSerializer
    queryset = Warrior.objects.all()
  • Маршрутизация
# warriors_app/urls.py
urlpatterns = [
    path('warriors/professions/', WarriorProfessionListAPIView.as_view()),
    path('warriors/skills/', WarriorSkillListAPIView.as_view()),
    path('warriors/<int:pk>/', WarriorRetrieveAPIView.as_view()),
    path('warriors/<int:pk>/delete/', WarriorDestroyAPIView.as_view()),
    path('warriors/<int:pk>/update/', WarriorUpdateAPIView.as_view()),
]

Архитектура проекта¶

Структура базы данных¶

Warrior (Воин)
├── id (ID)
├── name (Имя)
├── race (Раса)
├── level (Уровень)
├── profession (Профессия) → Profession.id
└── skill (Навыки) → Skill (ManyToMany через SkillOfWarrior)

Profession (Профессия)
├── id (ID)
├── title (Название)
└── description (Описание)

Skill (Навык)
└── title (Название)

SkillOfWarrior (Навыки воина)
├── warrior (Воин) → Warrior.id
├── skill (Навык) → Skill.id
└── level (Уровень освоения)

Принципы REST¶

  • GET - получение данных
  • POST - создание новых ресурсов
  • PUT/PATCH - обновление ресурсов
  • DELETE - удаление ресурсов

Вывод¶

В рамках практического задания был успешно разработан REST API для системы управления воинами с использованием Django REST Framework. Реализованы все требуемые эндпоинты, включая операции CRUD для навыков и воинов, с поддержкой вложенной сериализации связанных данных. Применение Generic-классов позволило значительно сократить объем кода при сохранении полной функциональности. API полностью соответствует принципам REST и предоставляет удобный интерфейс для взаимодействия с данными через стандартные HTTP-методы. Все эндпоинты протестированы и готовы к использованию, что подтверждает успешное выполнение поставленных задач по созданию полнофункционального веб-API.
